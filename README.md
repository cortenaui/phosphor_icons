# Phosphor Icons for CortenaUI

A comprehensive icon library for the CortenaOS ecosystem, providing the Phosphor icon family for Jetpack Compose and Compose Multiplatform.

This library bundles thousands of high-quality vector-like icons from [Phosphor Icons](https://phosphoricons.com/) using an efficient font-based rendering engine integrated seamlessly with CortenaUI's components.

## Features

- **6 Icon Weights**: Regular, Bold, Light, Fill, Thin, and Duotone styles for every single icon.
- **Compose Native**: Built specifically for Compose Multiplatform with a simple composable API.
- **Lightweight**: Uses a font-based backend instead of individual SVG/vector drawables, vastly reducing APK/app size.
- **CortenaUI Integrated**: Designed to work flawlessly with `framework.cortena.ui.components.Icon`.
